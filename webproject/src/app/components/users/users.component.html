Examples of Role-Based Data Access

Student Fees Page

  • Admin/Accounting: See all students' fees, can create invoices, mark payments for any student
  • Student: See only their own fee record, can view invoice and payment history

Staff Payroll Page

  • Admin/Accounting: Full access to view and manage all payroll entries
  • Student: Cannot access this page (route is protected)

Department Budget Page

  • Admin/Accounting: Full access to view and manage department budgets
  • Student: Cannot access this page (route is protected)
